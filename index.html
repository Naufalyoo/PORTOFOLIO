Mega Cyber Portfolio V7

Deskripsi: Proyek pamungkas pengembangan web statis. Dibangun tanpa framework, menggunakan ratusan baris CSS murni untuk menciptakan pengalaman *Sci-Fi* dan antarmuka layaknya terminal peretas.

Fitur Kunci: Virtual JS Terminal File System, Matrix Rain Background, Modal Windows, Intersection Observer Animations.

> Tech Stack: HTML5, Advanced CSS3, DOM JS.

HealthyLife BMI Web App

Deskripsi: Membantu pengguna memonitor kesehatan melalui kalkulasi indeks massa tubuh otomatis. Antarmuka didesain sebersih mungkin menggunakan gradien warna untuk kenyamanan visual.

> Tech Stack: HTML5, CSS Flexbox, JavaScript Math Logic.

Arduino Smart Sensor

Deskripsi: Melibatkan perangkat keras mikrokontroler (Arduino Uno) untuk membaca data dari sensor analog/digital. Sebuah eksplorasi dasar tentang logika *Internet of Things (IoT)* dan otomasi komponen elektronika sederhana.

> Tech Stack: Arduino Uno Board, C++, Jumper Cables.
